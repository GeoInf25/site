📑 LINUX COMMANDS:


Start the virtual machine via "Boot TinyCore" and open the Terminal, then try the following commands:

✦ echo ... : it displays messages or variables
✦ pwd: it shows your current directory
✦ ping -c 1 8.8.8.8: it checks connectivity to Google (sending one packet)
✦ ls -l: it shows detailed information about files
✦ cd ..: it means "change directory", which lets you move to the parent folder
✦ date: displays day, month, time, timezone, and year
✦ whoami: prints only your current username
✦ cat /etc/os-release: get operating system identification information
