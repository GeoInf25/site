📘 SOME NOTES:

• Disk installation of SliTaz 5.0 i486 (32-bit) via QEMU, with the management of the related partition using GParted;

• Setup of the v86 Emulator, bypassing the Grub Bootloader; splitting the created .img Disk into "Chunks" (compressed in .zst format) using v86's own Python script split-image.py;

• Added "Nasm" and "Tcc" packages for managing Assembly Scripts (launch "run_result00.sh" on Desktop);

• Ability to change the keyboard layout using the "tazkeymap" command;

• Possibility to add additional Fonts using the commands "tazpkg get-install get-msttcorefonts", "get-msttcorefonts";

• Use of "tazpkg get-install numlockx && numlockx on" to enable NumPad;

• Ability to test the "SliTaz" Environment / Operating System, with particular reference to the Xterm Terminal.


📘 ADDITIONAL NOTES:

• Tests and changes carried out take place within the Browser and the Client's own RAM (normally without saves);

• Click inside the Canvas (SliTaz Desktop image) to "capture" the mouse cursor (press Esc to exit).
